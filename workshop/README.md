# AWS Workshop Workspace

This directory stores hands-on AWS workshops.

Each workshop should live in its own subdirectory and be treated as an independent learning project that can later become a separate Git repository.

Recommended structure:

```text
workshop/
└── workshop-name/
    ├── README.md
    ├── notes/
    ├── labs/
    ├── infra/
    ├── scripts/
    ├── troubleshooting.md
    └── references.md
```

Vietnamese is the primary language for notes and explanations. Keep AWS service names, commands, error messages, and official terms in English.
