# AWS Abuse Team - Prohibited Use of AWS Services

**Date**: 2026-05-11

## Câu hỏi

**English**: A cyber forensics team has detected that AWS owned IP-addresses are being used to carry out malicious attacks. As this constitutes prohibited use of AWS services, which of the following is the correct solution to address this issue?

**Tiếng Việt**: Cyber forensics team phát hiện AWS IP-addresses đang được dùng để thực hiện malicious attacks. Đây là prohibited use của AWS services, solution nào đúng để giải quyết vấn đề này?

## Đáp án đúng ✅

**Contact AWS Abuse Team**

**Tại sao?**
- AWS Abuse Team xử lý **prohibited use** của AWS resources
- Report khi AWS resources bị dùng cho **abusive behavior**
- Đây là team chuyên trách cho security abuse issues

## AWS Abuse Team

**Chức năng**:
- Xử lý prohibited/abusive use của AWS resources
- Investigate và take action với AWS accounts vi phạm
- Protect AWS infrastructure và customers

**Khi nào contact AWS Abuse Team?**

### ✅ **Scenarios cần report**

1. **Spam** - AWS resources gửi spam emails
2. **Port scanning** - Scanning ports từ AWS IPs
3. **DDoS attacks** - Distributed Denial of Service attacks
4. **Intrusion attempts** - Hacking attempts từ AWS IPs
5. **Hosting prohibited content** - Illegal/malicious content
6. **Malware distribution** - Phát tán malware từ AWS
7. **Copyright/trademark infringement** - Vi phạm bản quyền

**Ví dụ câu hỏi**: AWS IP addresses thực hiện malicious attacks → **AWS Abuse Team** ✅

### 📧 **Cách report**

**Email**: abuse@amazonaws.com

**Hoặc**: Report form tại https://aws.amazon.com/premiumsupport/knowledge-center/report-aws-abuse/

**Thông tin cần cung cấp**:
- AWS IP addresses hoặc resources involved
- Logs/evidence của abuse
- Timestamp của incidents
- Description của abusive behavior

## Các đáp án SAI ❌

### ❌ **Contact AWS Support**
**Tại sao sai?**
- AWS Support xử lý **technical issues**, không phải abuse
- Abuse issues phải contact **AWS Abuse Team**
- Support ticket không phải channel đúng cho abuse reports

**AWS Support dùng cho**:
- Technical problems
- Billing questions
- Architecture guidance
- Service issues

### ❌ **Contact AWS Developer Forum moderators**
**Tại sao sai?**
- Developer Forums là **community support**
- Moderators không handle abuse cases
- Không phải official channel cho security issues

**Developer Forums dùng cho**:
- Technical questions
- Community discussions
- Best practices sharing

### ❌ **Write email to Jeff Bezos**
**Tại sao sai?**
- Made-up option (distractor)
- Jeff Bezos không còn là CEO Amazon (Andy Jassy là CEO từ 2021)
- Không phải escalation path cho abuse issues

## AWS Abuse Team vs AWS Support

| Feature | AWS Abuse Team | AWS Support |
|---------|---------------|-------------|
| **Purpose** | Handle abuse/prohibited use | Technical support |
| **Contact** | abuse@amazonaws.com | Support tickets |
| **Scenarios** | Spam, DDoS, malware, attacks | Service issues, billing, architecture |
| **Response** | Investigate + take action | Troubleshoot + resolve |

## Ví dụ thực tế

**Scenario 1**: AWS EC2 instance gửi spam emails
- **Action**: Report to AWS Abuse Team ✅
- **NOT**: AWS Support

**Scenario 2**: AWS IP thực hiện port scanning vào company network
- **Action**: Report to AWS Abuse Team ✅
- **NOT**: Developer Forums

**Scenario 3**: EC2 instance không start được
- **Action**: Contact AWS Support ✅
- **NOT**: AWS Abuse Team

## Lưu ý

- AWS Abuse Team sẽ investigate và có thể **suspend/terminate** AWS accounts vi phạm
- Response time phụ thuộc vào severity của abuse
- Cung cấp đầy đủ evidence để investigation nhanh hơn
