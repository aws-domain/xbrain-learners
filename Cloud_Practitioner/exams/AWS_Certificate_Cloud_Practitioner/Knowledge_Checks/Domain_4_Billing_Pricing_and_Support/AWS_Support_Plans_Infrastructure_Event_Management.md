# AWS Support Plans - Infrastructure Event Management

**Date**: 2026-05-11

## Câu hỏi

**English**: Which of the following AWS Support plans provides access to Infrastructure Event Management for an additional fee?

**Tiếng Việt**: AWS Support plan nào cung cấp access đến Infrastructure Event Management với additional fee (phí thêm)?

## Đáp án đúng ✅

**Business**

**Tại sao?**
- Business Support có access đến **Infrastructure Event Management**
- Nhưng phải trả **additional fee** (phí thêm)
- **NOT included** trong base Business plan

## Infrastructure Event Management (IEM)

**Là gì?**
- AWS experts giúp plan và execute **large-scale events**
- Ví dụ: Product launches, marketing campaigns, migrations
- AWS team support trước, trong, và sau event

**Access**:
- ❌ Basic: Không có
- ❌ Developer: Không có
- ✅ Business: **Additional fee** (phải trả thêm)
- ✅ Enterprise: **Included** (miễn phí)

## So sánh 4 AWS Support Plans

### ❌ **Basic** (FREE)

**Features**:
- 24x7 customer service
- Documentation, whitepapers, forums
- **7 core Trusted Advisor checks**
- AWS Personal Health Dashboard
- ❌ **NO Infrastructure Event Management**

### ❌ **Developer** ($29+/month)

**Features**:
- Email support (business hours only)
- **General architectural guidance** (không contextual)
- 7 core Trusted Advisor checks
- ❌ **NO Infrastructure Event Management**

**Use case**: Testing, early development

### ✅ **Business** ($100+/month)

**Features**:
- **24x7 phone, email, chat** support
- **Contextual architectural guidance** (specific use-cases)
- **Full Trusted Advisor checks**
- ✅ **Infrastructure Event Management** ← **Additional fee**

**Use case**: Production workloads

### ✅ **Enterprise** ($15,000+/month)

**Features**:
- 24x7 support + **Technical Account Manager (TAM)**
- Contextual architectural guidance
- Full Trusted Advisor checks
- ✅ **Infrastructure Event Management** ← **INCLUDED** (miễn phí)
- Proactive/preventative programs
- Concierge-like service

**Use case**: Mission-critical workloads

## So sánh Infrastructure Event Management

| Plan | IEM Access | Cost |
|------|-----------|------|
| **Basic** | ❌ NO | N/A |
| **Developer** | ❌ NO | N/A |
| **Business** | ✅ YES | **Additional fee** ✅ |
| **Enterprise** | ✅ YES | **Included** (no extra fee) |

## Key Point

**Infrastructure Event Management**:
- Business: **Additional fee** (phải trả thêm) ✅
- Enterprise: **Included** (miễn phí)
- Basic, Developer: **Không có**

**Nhớ**:
- Business = IEM available nhưng **phải trả thêm**
- Enterprise = IEM **included** trong plan

## Bảng tổng hợp AWS Support Plans

| Feature | Basic | Developer | Business | Enterprise |
|---------|-------|-----------|----------|------------|
| **Price** | FREE | $29+/month | $100+/month | $15,000+/month |
| **Support Access** | Customer service | Email (business hours) | 24x7 phone/email/chat | 24x7 + TAM |
| **Architectural Guidance** | ❌ | General only | Contextual | Contextual |
| **Trusted Advisor** | 7 core checks | 7 core checks | Full checks | Full checks |
| **IEM** | ❌ | ❌ | **Additional fee** ✅ | **Included** |

## Lưu ý cho bài thi

Câu hỏi hỏi: **"additional fee"** (phí thêm)
→ Đáp án: **Business** ✅

Nếu hỏi: **"included"** (miễn phí)
→ Đáp án: **Enterprise**
