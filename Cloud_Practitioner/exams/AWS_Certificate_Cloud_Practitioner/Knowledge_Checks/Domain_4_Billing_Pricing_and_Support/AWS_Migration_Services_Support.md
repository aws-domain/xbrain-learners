# AWS Migration Services and Support

**Date**: 2026-05-11

## Câu hỏi

**English**: A startup wants to migrate its data and applications from the on-premises data center to AWS Cloud. Which of the following options can be used by the startup to help with this migration? (Select two)

**Tiếng Việt**: Một startup muốn migrate data và applications từ on-premises data center lên AWS Cloud. Startup có thể dùng options nào để giúp migration này? (Chọn 2)

## Đáp án đúng ✅ (Chọn 2)

### 1. **AWS Professional Services + AWS Landing Zone**

**AWS Professional Services**:
- Global team of experts
- Supplement your team với specialized skills
- Help achieve quick results
- Consulting cho complex migrations

**AWS Landing Zone**:
- Solution để setup **secure, multi-account AWS environment**
- Based on AWS best practices
- **Automate setup** của environment
- Implement **initial security baseline**
- Create core accounts and resources

**Kết hợp**: Professional Services + Landing Zone = **Accelerate infrastructure migration**

### 2. **AWS Partner Network (APN)**

**APN**:
- Global partner program
- Technology and consulting businesses
- Build **custom solutions** for customers
- Experts giúp infrastructure migration

**Use case**: Work với APN experts để build custom migration solution

## Các đáp án SAI ❌

### ❌ **Raise support ticket with AWS Support**
**Tại sao sai?**
- AWS Support **KHÔNG giúp** complex infrastructure migration
- Support chỉ giúp technical issues, không phải migration consulting

### ❌ **Consult moderators on AWS Developer Forums**
**Tại sao sai?**
- Made-up option (không có thật)
- Forums không phải professional migration service

### ❌ **Use AWS Trusted Advisor to automate migration**
**Tại sao sai?**
- Trusted Advisor = **Best practices recommendations**
- Giúp về cost optimization, security, performance
- **KHÔNG automate** infrastructure migration

**Use case**: Check best practices, không phải migration tool

## So sánh

| Service | Purpose | Migration Support |
|---------|---------|-------------------|
| **Professional Services** | Expert consulting | ✅ Complex migration |
| **APN** | Partner solutions | ✅ Custom migration |
| **AWS Support** | Technical support | ❌ Not for migration |
| **Trusted Advisor** | Best practices | ❌ Not migration tool |
| **Developer Forums** | Community help | ❌ Not professional |

## Key Point

**Complex infrastructure migration** → Cần **experts/consulting**:
- AWS Professional Services + Landing Zone ✅
- AWS Partner Network (APN) ✅

**KHÔNG dùng**:
- AWS Support (không phải migration service)
- Trusted Advisor (chỉ recommendations)
- Forums (không professional)
