## Key Topics cần nắm chắc

- ✅ AWS Shared Responsibility Model
- ✅ IAM (Users, Groups, Roles, Policies)
- ✅ Well-Architected Framework (6 pillars)
- ✅ EC2 purchasing options (On-Demand, Reserved, Spot, Savings Plans)
- ✅ S3 storage classes
- ✅ VPC components (Subnets, IGW, NAT, Security Groups, NACLs)
- ✅ AWS Support plans
- ✅ AWS Organizations và Consolidated Billing
- ✅ Global Infrastructure (Regions, AZs, Edge Locations)
- ✅ Core services: EC2, S3, RDS, Lambda, CloudFront, Route 53
