# Product Overview

**XBrain Cloud Learning Repository** is a personal AWS knowledge base. It is not a deployed product or a single application codebase; it is a long-term study workspace for collecting, organizing, practicing, and refining AWS cloud engineering knowledge by topic.

## Purpose

- Store AWS notes, diagrams, quizzes, troubleshooting guides, and workshop learnings by domain
- Preserve durable mental models and practical lessons learned from AWS workshops
- Use Codex and Kiro to help plan, structure, and maintain learning artifacts
- Build toward cloud engineering competency across AWS foundations, databases, data, security, networking, serverless, observability, cost, and operations

## Primary Audience

A single learner (cloud engineer in training) supported by AI assistants for note-taking, lab planning, workshop guidance, and knowledge reinforcement.

## Language

Vietnamese is the primary writing language. Keep AWS service names, technical keywords, CLI commands, API names, and official feature names in English when that preserves accuracy. Explanations, summaries, learning plans, and troubleshooting notes should default to Vietnamese unless the surrounding document is already English.

## How AI Assistants Should Help

- Treat this repository as a knowledge base first, not an application to refactor aggressively.
- Prefer clarifying concepts, documenting tradeoffs, and creating reusable learning notes over generating production application code.
- When working with workshop content, capture what was learned, why each AWS service is used, common failure modes, and useful commands.
- Keep edits scoped and preserve existing topic organization unless the user explicitly asks for a broader restructure.
